# Sentry Approve

The web page that makes approval codes for Sentry, for phones and iPads.
It is at https://l-l0011.github.io/Sentryfilter-approvals-page/

Open it from your own link (Sentry: Settings › Approving from far away, the
QR code or Copy link), then Add to Home Screen. Your household is in that
link, after the #, which a browser never sends to this website. The page
never connects anywhere and saves nothing: your half and the code stay on
your device.

These files are made by Sentry's `app/cmd/approvesite`. Don't edit them
here.
